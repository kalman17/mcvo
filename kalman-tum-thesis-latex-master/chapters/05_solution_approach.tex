\chapter{Solution Approach}\label{chapter:solution-approach}

This chapter presents the proposed system for improving camera pose and intrinsic estimation from casual video. The approach combines AnyCam's pose prediction pipeline with AnyCalib's calibration capabilities, introducing two contributions: (1)~the \emph{AnyCam~$\times$~AnyCalib integration}, which replaces AnyCam's 32-candidate focal length system with AnyCalib's continuous calibration, and (2)~the \emph{Multi-Frame Calibration Transformer} (MCT), which enforces calibration consistency across video frames.

Section~\ref{sec:architecture} describes the complete architecture---both inherited components and our additions. Section~\ref{sec:training} describes the training procedure, including data, losses, and the staged training pipeline.

\subsection{Calibration Branch: AnyCalib Integration + MCT}\label{sec:calib-branch}

AnyCam's 32-candidate focal length system is replaced with AnyCalib's calibration pipeline, augmented by the MCT for multi-frame consistency. The full calibration branch proceeds as follows:

\begin{enumerate}
    \item \textbf{Per-frame feature extraction.} Each of the $N$ input frames is independently processed by a frozen DINOv2 ViT-L/14 backbone, producing multi-scale spatial features at four resolutions (from transformer blocks 4, 11, 17, and 23):
    \begin{equation}
        \mathbf{F}_i^{(s)} \in \mathbb{R}^{1024 \times h_s \times w_s}, \quad s \in \{1,2,3,4\}, \quad i \in \{1,\ldots,N\}
    \end{equation}
    In vanilla AnyCalib, these features are decoded directly to produce per-frame calibration estimates, which can then be averaged across frames as a simple baseline. Our system instead inserts the MCT before decoding.

    \item \textbf{Multi-Frame Calibration Transformer (MCT).} For each scale independently, features from all $N$ frames are reshaped to $(h \cdot w) \times N \times 1024$, treating each spatial position as a separate sequence of $N$ frame tokens. Two layers of multi-head self-attention (8 heads, $d_{\text{head}} = 128$, FFN $1024 \to 4096 \to 1024$ with GELU, pre-layer normalisation) allow each spatial position to exchange information across frames. The attended features are then mean-pooled across the frame dimension:
    \begin{equation}
        \mathbf{F}_{\text{agg}}^{(s)} = \frac{1}{N} \sum_{i=1}^{N} \text{Attention}(\mathbf{F}_1^{(s)}, \ldots, \mathbf{F}_N^{(s)})_i
    \end{equation}
    The same transformer weights are shared across all four scales (${\sim}25$M parameters total). Attention operates only across the \emph{frame} dimension---spatial positions are independent batch items, so there is no spatial attention. The output has the same shape as a single-frame AnyCalib feature map, allowing the downstream decoder to be used without modification.

    \item \textbf{Decoding.} The aggregated features pass through the frozen Light-DPT decoder (a lightweight CNN decoder) and ray head (convex upsampling to full resolution), producing per-pixel 3D rays $\mathbf{R} \in \mathbb{R}^{H \times W \times 3}$.

    \item \textbf{Calibration fitting.} A pinhole model is fit to the predicted rays via RANSAC and least squares, yielding $(f_x, f_y, c_x, c_y)$. This step is non-differentiable.
\end{enumerate}

The key design choice is to aggregate at the \emph{feature level} rather than at the scalar output level. Averaging final focal length predictions discards the rich spatial structure in AnyCalib's features; MCT preserves this geometric information by operating on the intermediate representations before decoding.

\subsection{Pose Branch: AnyCam Pipeline}\label{sec:pose-branch}

The pose branch follows AnyCam's architecture (Figure~\ref{fig:anycam-pipeline}), with one modification: the 32-candidate system is replaced by a focal length embedding from the calibration branch.

\subsubsection{Frozen Backbone}

A DINOv2-small (ViT-S/14) backbone receives the input frames concatenated with precomputed depth maps (UniDepth) and optical flow fields (UniMatch) as additional input channels. It extracts CLS tokens from four transformer stages (blocks 3, 6, 9, 12), each of dimension 384. The backbone remains frozen throughout all training phases.

\subsubsection{Pose Neck (Trainable)}\label{sec:pose-neck}

The pose neck transforms backbone CLS tokens into temporally aggregated pose tokens via four stages:

\begin{enumerate}
    \item \textbf{Reassemble}: Projects each of four CLS tokens $\mathbf{h}_{\text{CLS}}^{(s)} \in \mathbb{R}^{384}$ through per-stage bottleneck dimensions $b_s \in \{48, 96, 192, 384\}$ to a common 128-dimensional representation.
    \item \textbf{Fusion}: Progressively fuses the four reassembled tokens using residual pre-activation blocks.
    \item \textbf{Interframe attention}: Eight layers of multi-head self-attention (4 heads) across all $N$ frames, enabling multi-frame pose reasoning.
    \item \textbf{Sequence token}: A learnable parameter that attends over all frame-wise tokens via cross-attention.
\end{enumerate}

Approximately 2.5M trainable parameters.

\subsubsection{Focal Length Embedding (Our Addition)}

The predicted focal length from the calibration branch is converted to an 8-dimensional harmonic embedding and concatenated with each pose token before the pose head. This conditions pose prediction on the actual calibration, replacing the discrete candidate embeddings used in the original 32-candidate system. Original AnyCam does not use focal embeddings.

\subsubsection{Pose Head (Trainable)}\label{sec:pose-head}

A two-layer MLP maps each 136-dimensional token ($128 + 8$) to a 7-dimensional output: unit quaternion (4D, normalised for rotation) and translation direction (3D). Approximately 21K parameters.

\subsection{Training Data}\label{sec:training-data}

Training uses four datasets from AnyCam's original work: RealEstate10K~\parencite{zhou2018realestate10k} (indoor walkthroughs), YouTube VOS~\parencite{xu2018youtubevos} (diverse YouTube content), WalkingTours (urban walking), and OpenDV (driving). All data is preprocessed offline: optical flow (UniMatch), depth (UniDepth), and per-frame calibration (AnyCalib) are computed for all consecutive frame pairs. The per-frame AnyCalib predictions serve as both naive-averaged calibration during Phase~A and as pseudo ground truth for the calibration anchor loss during training.

\subsection{Multi-Frame Consistency via Flow Composition}\label{sec:flow-composition}

Training uses 4-frame windows ($\text{max\_ahead}=3$). To enforce multi-frame consistency without computing all $\binom{N}{2}$ pairwise flows, long-range flows are composed from consecutive flows through bilinear interpolation:
\begin{equation}
    \mathbf{w}_{1 \to 3}(u,v) = \mathbf{w}_{1 \to 2}(u,v) + \mathbf{w}_{2 \to 3}\bigl((u,v) + \mathbf{w}_{1 \to 2}(u,v)\bigr)
\end{equation}
This yields 5 training pairs (3~consecutive + 2~composed) from $O(N)$ flow computations. Relative poses are similarly composed via SE(3) composition. Preliminary experiments (Appendix~\ref{chapter:preliminary-results}) identified $\text{max\_ahead}=3$ as optimal, balancing temporal context against composition error accumulation.

\subsection{Loss Functions}\label{sec:losses}

The training loss combines four terms:

\paragraph{Flow reprojection loss (main signal).} For each frame pair, the predicted pose, depth, and intrinsics induce an optical flow field. The Laplacian negative log-likelihood between induced and observed flow (from UniMatch), weighted by a learned per-pixel uncertainty $\sigma$, provides the primary self-supervised training signal.

\paragraph{Calibration anchor loss.} For small camera displacements ($R \approx I$, $\mathbf{t} \approx 0$), the reprojection equation simplifies to $\mathbf{K}^{-1}(d\,\mathbf{K}\mathbf{x}) \approx \mathbf{x}$---the intrinsic matrix cancels out, leaving calibration unconstrained by the flow loss. To prevent $\mathbf{K}$ from drifting to arbitrary values, a calibration anchor penalises deviations from AnyCalib pseudo ground truth: $\mathcal{L}_\text{anchor} = \|\mathbf{K}_\text{pred} - \mathbf{K}_\text{AnyCalib}\|$.

\paragraph{Composed flow loss.} The multi-frame loss combines consecutive and composed pairs with down-weighting:
\begin{equation}
    \mathcal{L}_{\text{multi}} = \sum_{i=1}^{N-1} \mathcal{L}_{\text{flow}}^{(i \to i+1)} + \lambda_{\text{comp}} \sum_{j>i+1} \mathcal{L}_{\text{flow}}^{(i \to j)}
\end{equation}
where $\lambda_{\text{comp}} = 0.1$ accounts for reduced reliability of composed flows.

\paragraph{Pose consistency loss.} Forward-backward consistency: $P^{i \to j} \cdot P^{j \to i} \approx I_4$.

The total loss for Phase~C is $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{multi}} + \lambda_{\text{calib}} \mathcal{L}_{\text{anchor}}$ with $\lambda_{\text{calib}} = 10^{-4}$.

\paragraph{Phase A: Pose head initialisation.} The pose head is fine-tuned from a pretrained AnyCam checkpoint using static AnyCalib calibration (naive per-frame averaging). This validates that AnyCalib can replace the 32-candidate system and provides a warm start for subsequent phases.

\paragraph{Phase B: MCT pre-training.} Only the MCT is trained, using the calibration reprojection loss $\mathcal{L}_\text{calib}$ against AnyCalib pseudo ground truth. The RANSAC calibrator is non-differentiable, so Phase~B bypasses it: MCT's predicted rays are projected back to image coordinates using pseudo ground truth calibration, and the MSE provides the training signal:
\begin{align}
    u^{\text{proj}} &= f_x \cdot \frac{R_x}{R_z} + c_x, \quad
    v^{\text{proj}} = f_y \cdot \frac{R_y}{R_z} + c_y \\
    \mathcal{L}_{\text{calib}} &= \frac{1}{HW} \sum_{p} \|(u^{\text{proj}}_p, v^{\text{proj}}_p) - (u_p, v_p)\|^2
\end{align}
All backbone components remain frozen. This isolated pre-training ensures that the MCT is initialised to produce reasonable calibration estimates before being exposed to the complexity of joint training, preventing degenerate solutions.

\paragraph{Phase C: Joint training.} The pose neck, pose head, and MCT are trained jointly using the combined loss. Both DINOv2 backbones, the DPT decoder, UniDepth, and UniMatch remain frozen---approximately 27.5M of 370M total parameters are trainable (7.5\%).
