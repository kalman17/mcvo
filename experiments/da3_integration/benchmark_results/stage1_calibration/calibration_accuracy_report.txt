EVALUATION METHODOLOGY
--------------------------------------------------------------------------------
For each frame pair:
1. Run AnyCalib on both frames to get per-frame predictions
2. Extract visual tokens (DINOv2 for Stage 1/2, AnyCam for Stage 3)
3. Run DA3 calibration head to predict mean calibration
4. Compute GT mean calibration from the pair
5. Calculate relative errors: |predicted - GT| / GT * 100%
